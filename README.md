# Mieszko Mahboob — portfolio

Osobista strona portfolio zbudowana w Next.js/Vinext, GSAP i Three.js. Treść pokazuje realne role Mieszka: Zgrywa Studio, Generatywni i własne laboratorium projektowe.

## Lokalnie

```bash
npm install
npm run dev
```

Strona działa pod [http://localhost:3000](http://localhost:3000).

## Weryfikacja

```bash
npm run lint
npm run build
npm test
```

## Materiały

- Fonty: Roobert i Romie z oficjalnego pakietu identyfikacji Zgrywy.
- Logo: oficjalne pliki Zgrywa Studio.
- Fotografie obiektów: Tomek Albin.

Szczegóły strategii i art direction znajdują się w `PRODUCT.md` oraz `DESIGN.md`.
